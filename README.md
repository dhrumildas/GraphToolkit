# MSc_CGT_Case_Study

This is the playable case-study build developed for the MSc Computer Games Technology project.

## How to Play

Open the `Final_Build` folder and run:

`MSc_CGT_Case_Study.exe`

## Controls

- **W / A / S / D** — Move
- **Space** — Jump
- **E** — Interact with characters and objects
- **F1** — Return to the main menu

## Objective

Explore the environment, interact with the characters and objects, and progress through the Bazaar and Vault scenarios.

Dialogue choices and previous actions may affect later events and character responses.

## If You Get Stuck

Press **F1** at any time to return to the main menu and restart the case study.
